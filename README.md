⚽ Football Performance Data Analysis

Overview

This project explores the use of data engineering and data science methods to analyse football performance data.

The objective is to process a large-scale dataset collected from player activity, extract meaningful performance indicators, and investigate individual athletic profiles over time.

The project was developed as part of the Master’s degree in Sport Sciences — Engineering & Ergonomics of Physical Activity, Sport, Health & Artificial Intelligence (2SIA) at the University of Montpellier.

⸻

🎯 Objectives

The project focuses on the following objectives:

* Process and structure large-scale football performance data
* Clean and transform raw data for analysis
* Design and compute relevant Key Performance Indicators (KPIs)
* Generate descriptive statistics across different time scales
* Characterise individual athletic profiles
* Explore relationships between physical performance variables
* Develop reproducible and interpretable data analysis workflows

⸻

📊 Data Analysis

Data Engineering

The data processing pipeline includes:

* Data ingestion and organisation
* Data cleaning and quality control
* Data transformation
* Temporal aggregation
* Feature preparation for statistical analysis

Performance Indicators

Several indicators are calculated to characterise players’ physical activity, including:

* Total distance covered
* Running intensity
* Accelerations and decelerations
* Speed
* External workload
* Activity profiles over time

These indicators can be analysed at different temporal scales to identify variations in physical activity and individual performance profiles.

Individual Athletic Profiling

A specific focus is placed on individual player profiling, investigating relationships between variables such as:

* Speed
* Acceleration
* Distance covered
* Running intensity

The objective is to move beyond aggregated team-level statistics and provide a more individualised representation of athletic characteristics.
