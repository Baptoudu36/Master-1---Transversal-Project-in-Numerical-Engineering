# Manipulation de données volumineuses en football et analyses

## Objectifs du cours

Le cours compotera 4 sessions TD de 2h. Vous devrez travailler sur le sujet pendant ces temps et en dehors afin de livrer le rapport attendu. 
L'objectif global du projet est d'appréhender un jeu de données volumineux, de le manipuler, d'en extraire des informations pertinentes et ayant un intérêt pratique pour la discipline/métier concerné(e).

## Livrable attendu

A partir d'une base de données et de fichiers plats, vous produirez un rapport couvrant différents aspects:
- Data engineering: manipulation de données volumineuses \
- Data science: analyses statistiques portées sur ces données par le calcul de **KPI** et de **statistiques résumées** sur divers horizons temporels (e.g. aggrégations de types sommes, moyennes), et **modélisation de profils athlétiques individuels** sur l'ensemble de la période étudiée (e.g. Profils accélération ~ vitesse). \
Par ailleurs, des KPI spécifiques à chacun, basés sur leur propre activité et qualités physiques et normalisés, seront appréciés (e.g. intervalles de distances parcourues à des intensités données). \

Le projet devra être rendu pour le **16 février 2026** au plus tard. Il devra être remis sous forme de rapport pdf avec l'ensemble des codes, exécutables et documentés. 

Les langages de programmation acceptés sont R et python. 

Les notebooks (e.g. .ipynb, .rmd) sont acceptés en complément du pdf.

Il est **recommandé** de développer les analyses sur un échantillon restreint. La pertinence des méthodes employées prévaudra sur le volume de données analysées.
